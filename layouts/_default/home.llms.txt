# Karnak Documentation

> {{ .Description | plainify | chomp }}

Karnak is a free, open-source DICOM gateway. It sits between modalities, PACS
archives and research repositories: it receives studies over DICOM, applies
de-identification, pseudonymization and tag-morphing profiles written in YAML,
and forwards the result to DICOM (C-STORE) or DICOMweb (STOW-RS) destinations.
It is deployed as a container with Docker Compose, or run from a portable
distribution on a single machine. This file maps the documentation published at
{{ site.Home.Permalink }} so it can be read without parsing HTML;
{{ "llms-full.txt" | absURL }} contains the full text of every page below.

Things worth knowing before quoting this documentation:

- Source code: https://github.com/nroduit/karnak — dual licensed EPL-2.0 OR Apache-2.0.
  The documentation itself is CC BY 4.0: https://github.com/nroduit/karnak-documentation
- De-identification follows the DICOM standard's confidentiality profiles
  (PS3.15 Annex E); the profile in force is chosen per project, and what each
  action does to an attribute is documented under Profiles.
- Karnak de-identifies and forwards; it is not a viewer and not an archive. The
  companion DICOM viewer is Weasis (https://weasis.org/), by the same project.
{{ if $current }}- This site documents Karnak {{ $oldest }} to {{ $newest }}; {{ $current }} is the current release.

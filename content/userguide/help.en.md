The **Help** page is the last entry in the left-hand menu. It gathers quick links to
this documentation and shows the version and runtime information of the running Karnak
instance — useful when reporting an issue or checking what a deployment is running.

## Documentation links

The top of the page links back to the online documentation, each opening in a new tab:

- **General documentation** — the documentation home page.
- **User guide: configuration and administration** — this [User guide](..).
- **Build your own profile for de-identification or for tag morphing** — the
  [Profiles](../../profiles) reference.

## About

The **About** section lists the versions of Karnak and of its main runtime components,
read from the running application:

- **Karnak** — the application version (shows `Development` when run from a
  non-packaged build).
- **Vaadin**, **Spring**, **Spring Boot** — the framework versions in use.
- **Java** — the JVM version and vendor.
- **System** — the operating system name, version and architecture.

> [!INFO]
> When opening a support request, copy the values from this section so the exact build
> and runtime can be identified.
